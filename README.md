# Portofolio Muhammad Thufeil Putrayama
Desain ulang. HTML, CSS, dan JavaScript murni, tanpa framework.

Jalankan: `node serve.js` lalu buka http://localhost:3333/ (atau buka index.html langsung).

Berkas: index.html, style.css, app.js, data.js, showcase.js, chatbot.js, serve.js, assets/.
Sertifikat, layar presentasi, dan video YouTube diatur lewat data.js (petunjuk di bagian atas tiap blok).
Menambah sertifikat atau layar presentasi: edit data.js saja (petunjuk ada di bagian atas berkas itu).
Chatbot: hanya UI. Sambungkan otaknya lewat CHAT_API_URL atau window.PortfolioChat.handler di chatbot.js.
Gambar content_creation_thumb diperkecil (6 MB menjadi sekitar 0,3 MB) agar halaman cepat dimuat.
